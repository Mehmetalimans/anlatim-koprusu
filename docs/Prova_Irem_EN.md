# İrem — İngilizce okuma kartı

Konuşulacak toplam metin: 280 kelime. Gerçek süre henüz ölçülmedi. Canlı uygulama cümleleri kayıtta gerçekten gösterilen davranışla örtüşmeli.

## B. 0:40-1:10 - How it works / İrem

We use Python and Streamlit.
The student chooses a text and copies a difficult phrase.
The model gives an explanation and a separate example.
It also creates a question.
The student chooses an answer and writes a short reason.
The app needs internet access for the model.
We will show the full process with an economics example.

## C. 1:10-1:35 - Choose the phrase / İrem

Deniz chooses to study.
His other choices are a concert and a film.
He prefers the concert to the film.
I select the phrase about the best alternative he gives up.
Then I ask the model to explain it.

## D. 1:35-2:05 - Read the explanation / İrem

The explanation stays next to the source.
We can check what it means.
Deniz would choose the concert if he did not study.
So the concert is the best alternative he gives up.
We should not add the concert and the film together.
The extra example has a separate label.

## E. 2:05-2:40 - Try a wrong reason / İrem

I will try a common mistake.
I will choose an answer that adds all the other options together.
My reason says that every option we give up should count.
The feedback should explain what is wrong with this reason.

## F. 2:40-3:25 - Try again / İrem

I will try again using the best alternative.
We check the chosen option in code.
The model comments on the written reason.
A correct option can still have a wrong reason, so we check both.
We also review the demo answer keys because AI can make mistakes.

## H. 4:00-4:35 - Prompts and checks / İrem

We use separate prompts for explanations and feedback.
Sixty-eight automated tests passed with controlled responses and no live model calls.
We still need to compare the two prompts using the same texts.
We will check the meaning, the questions and the feedback.
Learning gains have not been measured.
